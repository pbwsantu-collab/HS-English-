# Contributing to EnglishMaster AI

Thank you for your interest in contributing! Please follow these guidelines:

- Fork the repository and create a feature branch from feature/englishmaster-ai-mvp for new work during initial development.
- Keep commits small and focused; follow the commit strategy in the project README.
- Write clear commit messages and include tests for new behavior.
- Ensure TypeScript builds and linting pass before opening a PR.

See CODE_OF_CONDUCT.md for expected behaviour.
